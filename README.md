# نظام ماهر البحيري للاستيراد والتصدير

نظام محاسبة وتشغيل لشركة توريدات غذائية، بيحل محل ملف الإكسل (`شيتات_محاسبة_توريدات_غذائية_محدثة.xlsx`)
بنفس عملياته وأعمدته، لكن بأرصدة تلقائية وفواتير وسندات ومنع للأخطاء.

> الفولدر القديم `htdocs 2/` وملف `if0_42969075_root.sql 2` هما النظام القديم (نقطة بيع محل تجزئة) — **النظام الجديد في `htdocs/`**
> ومالوش علاقة بالقديم ولا بقاعدة بياناته.

## المميزات (مأخوذة من شيتات الإكسل)

| شيت الإكسل | في النظام |
|---|---|
| المشتريات | فواتير مشتريات متعددة الأصناف: خصم، نقل، ضريبة قيمة مضافة، رسوم أخرى، إجمالي تلقائي، حالة سداد (مدفوع/جزئي/آجل)، منع تكرار رقم فاتورة المورد |
| العملاء | حساب مستقل لكل عميل: رصيد سابق + فواتير − تحصيلات = رصيد متبقٍ، موعد الاستحقاق، حالة الحساب (نشط/مغلق/متأخر) تلقائياً |
| الموردين | نفس الفكرة منفصلة تماماً عن العملاء |
| المخازن | أصناف بكود ووحدة وحد إعادة طلب، أرصدة (أول المدة + وارد − منصرف)، حالة «اطلب بضاعة»، عدة مخازن، تحويل بينها، إذن استلام/صرف/تسوية جرد |
| الخزينة والمصروفات | مقبوضات/مدفوعات بتصنيفات الإكسل، رصيد أول وآخر كل حركة تلقائي، خزينة نقدية منفصلة عن البنك، إيداع/سحب بنكي |

وبما إن شيتات الإكسل بتتكلم عن مبيعات وتحصيلات وسداد، أضفنا: **فواتير المبيعات** و**سندات القبض والصرف** (بتوزّع المبلغ على الفواتير تلقائياً)،
بالإضافة إلى: لوحة رئيسية، تقارير (أعمار الديون، المصروفات، ملخص الفترة...)، تصدير Excel لكل قائمة، طباعة، مستخدمين وصلاحيات، سجل عمليات.

## قواعد النظام (من «قواعد مهمة» في الإكسل)
- مستند لكل حركة (رقم فاتورة المورد ورقم إيصال الخزينة إجباريين).
- الأرصدة كلها بتتحسب من الحركات — ولا رصيد بيتكتب يدوياً.
- الفاتورة والسند ما بيتعدلوش؛ بيتلغوا (والإلغاء بيعكس أثره بالكامل) ويتسجل في سجل العمليات.
- مفيش بيع/صرف أكتر من رصيد المخزن، ولا دفع أكتر من رصيد الخزينة (قابل للتعطيل من الإعدادات).

## التثبيت على الاستضافة (InfinityFree أو أي استضافة PHP + MySQL)
1. من لوحة الاستضافة اعمل **قاعدة بيانات MySQL جديدة فاضية**، وسجّل بياناتها (Host / DB / User / Password).
2. ارفع **محتويات فولدر `htdocs/`** (من الريبو) إلى فولدر `htdocs` في الاستضافة.
3. افتح `https://موقعك/install/` واكتب بيانات قاعدة البيانات وبيانات المدير، واضغط «تثبيت النظام».
   المُثبّت بيعمل الجداول، المخزن الرئيسي، حساب الخزينة وحساب البنك، وملف `config/env.php` (ممنوع يترفع على GitHub).
4. **امسح فولدر `install/`** من الاستضافة، وسجّل دخول من `auth/login.php`.
5. اتبع صفحة «دليل الاستخدام» داخل النظام: إعدادات الشركة ← أرصدة الخزينة ← الأصناف ← الموردين والعملاء ← التشغيل اليومي.

المتطلبات: PHP 8.0+ (مع PDO MySQL و mbstring) و MySQL 5.7+ أو MariaDB 10.3+.
تشغيل محلي (XAMPP): ضع الفولدر داخل `htdocs` وافتح `http://localhost/<الفولدر>/install/`.

## الهوية
اسم الشركة وألوانها (كحلي بحري + ذهبي + لمسة خضراء للغذاء) واللوجو في `htdocs/assets/css/app.css` و`htdocs/assets/img/logo.svg`.
غيّر الألوان من المتغيرات في أول `app.css`، وبدّل `logo.svg` بلوجو الشركة الفعلي.

## الاختبارات
```bash
php tests/services_test.php            # منطق المحاسبة والمخزون على قاعدة اختبار منفصلة (tests/env.test.php)
MB_ENV_FILE=tests/env.test.php php -S 127.0.0.1:8080 -t htdocs
php tests/e2e.php                      # اختبار فورمات حقيقية عبر HTTP (CSRF، صلاحيات، قفل الحساب)
bash tests/smoke.sh                    # فتح كل الشاشات والتأكد من خلوها من الأخطاء
```
(تحتاج قاعدة `maher_unit` ومستخدم `maher` أو عدّل `tests/env.test.php`.)
